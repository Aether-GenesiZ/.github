# Aether GenesiZ Corporation Group (ATGZ)

We build applied AI systems that run in production.

## What we do

- **Multi-agent infrastructure** — orchestration, delegation, and monitoring for AI agent fleets. First public release: [hermes-agents-monitor](https://github.com/Aether-GenesiZ/hermes-agents-monitor) — a realtime dashboard plugin for [Hermes Agent](https://github.com/NousResearch/hermes-agent).
- **Self-hosted LLM platforms** — model serving, routing, and evaluation on GPU infrastructure we operate ourselves.
- **Enterprise automation** — ERP platforms (Odoo), RAG assistants, and system integrations for real workloads.

## How we work

A small founding team that ships hands-on. Everything we run, we run on infrastructure we control — and when a piece of our stack is useful to others, we open-source it.

## Roadmap

Applied AI → agentic systems → applied robotics. One step at a time, with the operational parts — monitoring, reliability, tooling — taken as seriously as the research.
